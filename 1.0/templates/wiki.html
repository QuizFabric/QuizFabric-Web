📖 QuizFabric - How to Use

A Kahoot-style quiz system: the server hosts quizzes, and you join from a Nintendo 3DS or DS (or the website). This page is the quick guide for the handheld clients.

← Back to the quiz list

🎮 3DS Version

Install the QuizFabric3DS.cia (or run the .3dsx) and open it from the home menu.

Setup screen

The top screen shows the server address and build number. Touch the SERVER bar to change the IP and port (the production build has the server fixed - no bar).

Joining a game

  • Touch JOIN, then tap the rows to set your NAME, the 4-digit GAME PIN and your AVATAR, then press JOIN GAME.
  • The question appears on the top screen; tap your answer on the touch screen. Slider and puzzle questions are supported too.
  • Press B to leave a game.

Hosting from the 3DS

  • Touch HOST and pick a quiz. The top screen shows the GAME PIN (players join with it) and a CONTROL CODE.
  • Touch OPEN CONTROL PANEL (or use CONTROL on the main menu with the control code) to start the next question, reveal answers, toggle autoplay and kick players.

Solo play

Touch SOLO and pick a quiz to play it alone with scoring, no game code needed.

KAHOOT (download quizzes)

  • Touch KAHOOT and type a search query (or paste a Kahoot ID/link).
  • Pick a result (covers show on the top screen) - the quiz, its questions, images and GIFs are downloaded and it becomes yours to edit and host.
  • Rename it, then SAVE (B discards it).
  • The server limits downloads to 1 every 10 minutes / 10 per day per device (production).

Pre-caching & offline mode

  • In the solo/host quiz list: X pre-caches a quiz's photos and GIFs to the SD card. X+SELECT caches every quiz.
  • Y searches the quiz list.
  • Y on the setup screen switches to OFFLINE MODE - only SOLO (cached quizzes) and DELETE (remove cached quizzes) are shown. Cached quizzes play fully offline; images load from the SD card ("Loading from cache").
  • Offline, Y checks the internet again to go back online.

🎮 DS / DSi Version

Run QuizFabricDS.nds from your flashcard / nds-bootstrap. Everything works with the touch screen; the top screen shows questions and the bottom screen the buttons.

Differences from the 3DS version

  • Wi-Fi: DS homebrew only supports open or WEP networks. On WPA2 you must make a hotspot. (Wi-Fi setup screen comes with the full release.)
  • No GIFs: the DS is not powerful enough to load GIFs - a GIF question shows "Cannot load GIF. DS is not powerful enough to load GIFs. Use a 3DS instead."
  • Pictures are very low resolution to save RAM - that is expected.
  • The background is a static picture (no animation) to save power.
  • Typing uses the touch-screen keyboard (tap a field to open it).

Everything else works like the 3DS

Join with a game PIN, host with the control code, solo play, KAHOOT downloads, pre-caching with X / X+SELECT and offline mode.

🌐 Website

On the website you can also upload or make quizzes, edit them, host games in the browser and steal quizzes from Kahoot or Blooket.

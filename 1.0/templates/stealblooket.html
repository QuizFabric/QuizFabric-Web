Paste a link to a public Blooket game (like https://dashboard.blooket.com/set/5fac96fe2ca0da00042b018f) or just the game ID at the end of the link. QuizFabric will download it and convert it.

Multiple-choice and true/false questions become multiple choice, typing questions become type-answer — other question types are skipped. Question images are downloaded too.

Note: Blooket only lets logged-in users browse games, so there's no search here — grab a game link from Blooket and paste it above.
